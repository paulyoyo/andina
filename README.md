## 📚 Contenido técnico

- 6 VLANs · TI / Finanzas / Ventas / VOIP / Administración / Parkeo
- Inter-VLAN routing · Router-on-a-Stick (Cisco 2811)
- DHCP centralizado · 5 pools, incluye option 150 para VoIP
- Telefonía IP · Call Manager Express con 6 extensiones (1001–1006)
- Hardening · SSH v2, native VLAN custom, parking, trunks restringidos
- OSPF área 0 · listo para escalamiento multi-sede

## 🧰 Stack

- Cisco Packet Tracer · simulación
- HTML / CSS / JavaScript vanilla · presentación
- Cisco IOS 15.1 · routers 2811 + switches 2960
